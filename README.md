# Techfest 2026 — Ideate Landing Page

A lightweight futuristic landing page concept for the Techfest IIT Bombay Ideate task.

## Files
- `index.html` — page structure
- `style.css` — responsive futuristic styling
- `script.js` — mobile menu interaction

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Create a GitHub repository, upload these three files to the root, then enable GitHub Pages from the repository's Pages settings.
